# 报告后的源码保留与召回核对

本轮把已有 canary/recall_probe 实验工具接入 SUBSYS、VERDICT。默认关闭，`AGENT_RECALL_CHECK=1` 启用。它连接此前的读取覆盖审计、必要证据清单、事实断言和独立源码复核；不计算新分数，不替代执行验证。

## 一次任务怎样运行

1. 宿主清点可完整解析的 C/C++/Rust 函数。因为报告引用只能在报告生成后确定，先在工作副本中准备候选标记，再在报告后选出实际提问集合。标记准备数量可能超过提问预算，不能将二者混称为被核对函数数。
2. 在副本候选函数的 start/mid/end 安全位置插入随机内联注释，不新增换行。短函数没有足够位置时只插入可用位置。原仓库不改动。预留两个非必要证据函数作未标记对照，并在普通任务提示中要求读取它们，提示不提 canary。
3. SUBSYS/VERDICT 经本地 RecordingProxy 调用模型。代理注入凭据，当前运行的 OpenCode 配置只有占位符；不改用户全局配置，不改变主任务已有工具权限。每次调用保存独立请求/响应日志、data/state、batch/session 对应关系，结束后压缩日志、清除该进程 TMPDIR 和可重新安装的 node_modules。
4. 原有读取覆盖检查照常运行。副本工具返回先按副本原文核对，再在确认去除插入注释后与原文件一致时，将行范围映射到原文件哈希。原始副本证据和映射后的证据均留档，不能靠改哈希掩盖其他源码变化。
5. 报告有效后冻结该次结果，按实际被采纳读取记录找到对应会话。宿主选择评价清单必要函数、报告引用所在函数，再抽查已完整返回的非关键函数。无标记对照只有确实完整返回过才能进入题目。
6. 复制该会话的 data/state，批量提问。提问 agent 权限为 `{"*":"deny"}`，不使用 OpenCode 1.14.48 的 `--fork`。有工具定义、响应工具调用或事件流工具调用时，提问不计为有效召回。提问分叉结束后删除分叉目录，不修改主会话。
7. 根据状态决定是否补读，并把涉及的函数关联到报告断言。补读使用新会话、新副本和新随机值；提示只包含目标位置和已清理的草稿，不包含题目答案或提问结果。原读取补证与本门槛共享补读预算，新增召回补读不会无限重置预算。
8. 被标记异常函数对应的结构化说法进入独立源码复核，包括标记被错认成另一函数时的两边。相关说法即使落在原普通复核数量之外，也会加入定向复核。复核缺证据仍保持未确认。

## 选择和预算

| 配置 | 默认值 | 含义 |
| --- | --- | --- |
| `AGENT_RECALL_CHECK` | 关闭 | 必须等于 `1` 才启用 |
| `AGENT_RECALL_MAX_FUNCTIONS` | `12` | 实际提问的函数名上限，包含无标记对照及虚构函数；允许 4–100 |
| `AGENT_RECALL_SAMPLE_RATIO` | `0.15` | 已完整返回、非关键、非对照函数的随机抽样比例；允许 0.1–0.2 |
| `AGENT_RECALL_CALLS` | `1` | 关键函数是否增加语法调用列表题，`0` 关闭 |
| `AGENT_RECALL_MODEL` | 主任务模型 | 可指定同一 provider 内的模型；换模型时记录实际提问模型，不能称为原模型的召回能力 |
| `AGENT_RECALL_DIR` | `data/recall_checks` | 仓库外的副本和持久记录目录 |

必要证据项可以增加 `score_impact`（0–100），由评测方指定排序影响。程序不从自由文本 `score_effect` 猜测分值。未配置时按同等影响处理，必要证据优先于一般引用，同级按稳定函数标识排序。

超过预算的函数留在 `selection.omitted`，不会视为已核对。对照不足两项时记录缺额，不伪造对照。每个参与核对的文件增加一个不存在的函数名。随机抽样保存种子；预算被关键项占满时也保留原定抽样数量和实际遗漏。

如果事先预留的无标记函数后来被报告引用，它不再作为 null 对照；记录未布置标记，下一次允许的补读将其加入标记候选。始终没有可用位置或预算时保留缺口。

## 保留和召回分别怎样判

标记 `present` 来自被采纳主会话最后一次生成请求，而不是完整磁盘历史。标题等辅助请求不替代主生成请求。保留原始请求序号，缺日志、记录不完整时为 `unknown`。

完整函数另行检查：核对最终请求中的工具返回行范围，或完整源码文本是否仍出现。标记仅在摘要中出现而源码不完整时，可以出现“标记 present，但完整函数未核对到”。不能把标记保留率叫成完整源码保留率。

| 条件 | 状态和动作 |
| --- | --- |
| 标记曾返回、仍在最终输入，且完整值答对 | `retained_recalled` |
| 标记曾返回、最终输入中不在 | `dropped`，安排补读和相关断言复核 |
| 标记仍在，但返回 null、部分值或其他错误值 | `present_not_recalled`，安排补读和相关断言复核 |
| 标记仍在，但报出另一个函数的值 | `misattributed`，两边相关断言复核；另一函数不在提问集合中也会关联 |
| 未标记/虚构对照返回非 null | `confabulation`，记录误报，不自动修改评分 |
| 没确认标记曾返回 | `not_observed`，交给既有读取覆盖机制解释，不能称为遗忘 |
| 缺日志或提问无效 | `unknown`，不凭空触发 dropped |

提问请求中的 `probe_present` 也单独记录。如果主报告结束时标记存在、分叉提问时又被压缩掉，标注 `probe_context_changed`，不当作“仍在提问上下文但召回失败”。召回率分母只包含主输入和提问输入中均确认 present 的已读标记；无日志时只保留答对率。

调用列表题按函数名提问，答案来自语法树中的调用表达式，单独判分。它不是动态调用图，也不证明被调用路径实际执行过。调用题答错会使对应断言进入复核。

标记不在请求中，不单独证明发生了自动压缩；也可能涉及其他上下文处理。报告用“已读标记不在最终请求中”表述，不自动将原因写成压缩。

## 报告和私有产物

交付前从 JSON、引用片段、HTML、Markdown 等本轮报告产物中清理标记注释和已知随机值。正文主动引用标记会被记为 `report_echo`。提问的原始答案仅留在私有记录，报告显示判定而不展示随机值。

新增“源码保留与召回核对”小节，按轮次、函数展示读取覆盖、源码范围保留、逐标记 present/提问状态、触发动作及最终状态。断言和普通关键结论旁保留依赖函数的核对历史。展示最终保留率、条件召回率、误归属和对照误报、调用题结果、提问输入 token；完整使用量和服务商返回的缓存命中量留在 JSON。

分叉复用会话历史和主 agent 提示，尽量利用供应商的前缀缓存。但禁用工具、更换模型和服务商缓存策略都会影响命中，不能保证全部前缀被缓存。未返回使用量时记未知，不填零。

每个调用的持久目录包含：

```text
copy/repo/                 本轮带新标记的副本
private/manifest.json      0600 答案映射，不传入提示或附件
private/probe.json         0600 原始提问结果
main/*.jsonl.gz            主任务请求和响应
probe/*.jsonl.gz           分叉提问请求和响应
opencode-data/accepted/    被采纳会话 data/state 和无真实 key 的配置
session.json               batch_id/session_ids 对应关系
mapped-audit.json           映射回原文件的读取记录
check.json                 本轮核对结果
recall.json                本次门槛的各轮汇总
```

原始副本工具事件仍使用现有读取审计目录。私有目录为 0700，答案文件为 0600；主任务启动前移除准备工具生成的答案文件，主任务结束后才落盘，不把其路径放进主任务。与原实验相同，这不是针对同一系统用户拥有任意文件系统权限的对抗隔离；本轮没有擅自改变主任务工具权限。

启用时不复用旧 SUBSYS 缓存。显式恢复旧阶段产物但没有本轮会话记录时显示未知，不补造保留/召回历史。开关关闭时不启动代理、不制作副本、不提问，现有交付内容保持原流程。

## 验收和此前方法的关系

本轮在本地假模型上验证正常召回、强制压缩后补读恢复、错误值触发复核、两个函数标记互换时两边进入复核。它使用真实 OpenCode 和 MCP，但不消耗真实模型 API。

工程回归还覆盖原仓库不变、标记不增加行、C 编译、报告清理、无日志保持未知、提问工具禁用、每轮新值和预算共享、源码证据映射、关闭时原输出字节不变、密钥不进入录制日志。最终数量和可复查产物见验收汇总。

这一步完善原计划第 3 条的报告后抽查，并连接第 2 条读取补证、第 4 条断言和已有第 5 条独立复核。此前的证据清单、引用验证和有限修订继续使用，不另建一套评价器。

仍待单独完成的工作：真实比赛仓库的付费 SUBSYS 验收（需用户确认）；断言的独立执行验证；基于评分影响的完整动作调度；已核验事实到评分的映射；普通注释/无标记对照、只收集标记的基线及更大规模效果实验。不能用本轮工程测试宣称这些研究问题已经解决。
