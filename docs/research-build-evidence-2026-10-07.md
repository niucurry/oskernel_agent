# 构建证据实验与继续选题的约束

本轮继续原目标，未重启交接禁止的三条旧研究主线。先核对当前生产与缓存状态，随后在新目录完成了构建证据最小原型、实际工具实验、生产修正和另一公开作者 OS 的准备实验。

## 新证据与决策

三个已有开发内核的五次编译器/二进制工具查询全部实际执行。生产 SMP 探测在 NuttX 上仅因 Bluetooth 协议中的 `smp_init` 名称给出“多核”；生成配置关闭 SMP。StarryX 实际 Cargo 指纹则启用 SMP，而平台配置为 1 CPU。这个例子表明功能开启与配置核数需要分开，也说明源码扫描可混入非目标平台和同名协议。没有完整捕获 C 编译参数，不能把当前生成头和缺失符号升级成整个构建语义真值。

候选“源码线索绑定现成构建证据”与配置/编译器强基线判定等价，**停止作为新算法投入**。这个结论来自明确的方法等价性，不是把工程测试当算法效果。没有复现 krepair，也没有验证按评审重要性选择构建优于它；整个构建配置方向不能因此被宣布不可行。原协议 H_system 的操作性组合出现，但严格的完整构建假设仍缺证据，修正审计保留该限制。

工程修改已保留：SMP 采集继续给出原路径和常量，将肯定多核/单核结论改为待验证线索，并明确同名、配置、平台与运行局限。四项新增语义回归覆盖 Bluetooth 同名、未启用分支、配置核数和无证据；连同相关现有检查 **105 passed**。该数量不代表论文效果。

## 对候选空间的影响

| 已考察候选 | 目前证据 | 继续投入的边界 |
|---|---|---|
| A：仅加入构建绑定 | 三个开发内核；普通配置/编译器已给相同结果 | 淘汰该新算法主张；评审目标如何改变构建选择仍未验证，不能宣布整个领域失败 |
| B：名称/身份变形找测试特化 | 前期 StarryX 的自然 ELF 后缀路由问题与适用性对照成立；普通合同/变形基线等效 | 保留系统线索；不能将同一机制的多个重复计成独立缺陷；第二内核尚未运行 |
| C：上游残余比较 | 前期 36 受控案例复现路径扣除风险；已知上游规范化 diff 等效 | 淘汰简单残余新算法；路径规则的工程问题仍存在，不能把一般队伍相似度解释为抄袭 |
| D：操作/状态门控解释判定 | 前期 392 扩展运行单元及独立早期控制；通用门控有反例、语义专用检查已有强基线，扩展强普遍性假设未达到冻结门槛 | 保留实证和日志工具；不能复用同一开发数据反复换阈值或将 syscall 干预误称自然内核缺陷 |
| F：仓库输入中的提示注入防御 | 本轮阅读直接相关原始论文与官方实现；没有本项目效果实验 | StruQ、TaskShield、RepoGuardBench 及代码注释攻击研究已有直接先例；单做输入隔离不足以支持新增方法，不开始无依据的 API 消耗 |

F 的来源：[StruQ 原始 USENIX Security 工作](https://www.usenix.org/conference/usenixsecurity25/presentation/chen-sizhe)、[TaskShield ACL 原论文](https://aclanthology.org/2025.acl-long.1435.pdf)、[RepoGuardBench 作者实现](https://github.com/DaoyuanLi2816/RepoGuardBench)、[代码评审注释攻击预印本](https://arxiv.org/html/2602.16741v1)。这些研究不证明本项目一定受攻击或防御有效；这里只用于约束一个简单候选的新颖性。A 的原论文、官方实现及编译器文档见实验 README。

## 第二内核准备与成本

NoAxiom 先前的 vendor 预算失败保留。资源压缩后新增了显式第二准备预算，使用原日期编译器、原 release/debug profile、锁定离线依赖，没有改模型、内核或测例。脚本第一次遗漏私有 cc 路径，完整记录并显式修正；第二次原始用户程序编译成功。内核随后因两个 target 合计体积超过 256 MiB 上限被停止，属于准备未知。

三次编译入口合计约 21.16 秒墙钟、32.44 CPU 秒；469 个原源文件 SHA 一致；**boot 0、方法运行 0、模型调用 0**。此仓库未增加有效内核样本，同一仓库的多阶段失败不能膨胀独立样本数。用户程序成功也不是内核有效性或论文方法效果。

五份新的可恢复缓存归档在验证完整内容后回收空间；原始源码、内核 ELF、所有负结果保留。归档校验的第一次硬链接错误发生在删除前，失败记录保留。2025 私有 Rust/LLVM 工具当前需恢复相应库后才能执行，2024 编译器保留；具体恢复命令、文件索引和限制见 [实验说明](../research/build_evidence/README.md)。准备故障不是研究方向无效的证据。

可复查材料：[冻结协议](../research/build_evidence/protocol.json)、[原始测量与强基线](../research/build_evidence/results.json)、[生产修正后观测](../research/build_evidence/production-after.json)、[新总账](../research/build_evidence/final-audit.json)、[NoAxiom 完整阶段](../research/noaxiom_contract_validation/README.md)。此前 392 个实际运行单元的总账未覆盖，新查询和编译没有混入该计数。目标继续保持：当前有可保留的系统改进和更多候选否定依据，还没有证据证明取得了真正合适的顶刊研究方法。
