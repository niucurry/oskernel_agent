# 第二阶段候选审计（不是选题成功声明）

只涉及描述系统。阅读预算、语义支持强度与评测的名称线索污染是不同问题，没有行为图/状态卡、条件 JSON 或压缩条件保持。

|候选|描述步骤、真实失败、评委信息|最近工作与新颖性限制|独立参考/强基线|成本、决定|
|---|---|---|---|---|
|按源码对象类型平衡阅读预算|取样/源码阅读；同一目录多个服务，默认片段常被说明文字占用；评委需找到子系统有哪些服务|RepoSummary 已做功能聚类/细粒度溯源，HGEN 已做分层文档；Lin & Bilmes 覆盖选择和 minimax 优化不能冒充新算法；本候选只检验对象覆盖目标的增量|维护者 ThreadX 服务手册的服务身份与 Ctags 定义交集；简单名称族轮询和按字节归一的词覆盖。衡量完整实现片段的暴露，不是生成摘要正确率|先无模型预检。24 KB 上与简单方法功能族持平且服务数更低，淘汰，不调对象组/提示挽救|
|按证据类型限制能力断言|引用/交付；存在行号不等于“已运行/兼容”；评委区分源码声明、实现和执行|ReFEree 已细粒度上下文核验；受控自然语言文档验证有长期工作；TRACE 已测量多制品冲突的信任分配。仅加“声明/实现/测试”标签属于工程约束，暂不立为论文方法|可以有限核验引用/日志来源，但任意能力断言仍需独立参考；简单来源类型规则必须作为强基线|本阶段不投入模型；先淘汰普通标签拼装，未证明足够差异|
|隔离名称线索后的语义可定位性评测|评测/交付门禁；模型可能凭 API 名称答对而忽略错误职责；评委真正需要报告正文把功能与来源对应|QAEval 已用问答衡量内容；名称遮蔽/鲁棒性已研究。新问题必须是描述评测的身份污染，不能把换一个读者或遮蔽本身说成新方法|维护者原 Purpose 行作题意，正确源码身份作答案；对同一内容正常/错配/仅名称控制。简单职责文本检索必须参与|实际 8 次请求、12,356 token，发现明确身份污染；遮蔽能去掉这组污染，但精确词检索控制已全部解出，暂只保留诊断，不宣布独立论文方法|

原始资料：

- RepoSummary 原文 [arXiv](https://arxiv.org/html/2510.11039v1)。已读方法和评价：JDT、方法/文件摘要、语义矩阵+依赖矩阵、Leiden、功能/epic 文档；本文仍用模型判断覆盖，并报告有限人工相关性。没有以其标题宣布功能组织空白。本次检索未找到与论文绑定且核实的公开完整实现；同名 Git 历史项目不是本文。
- HGEN 原文 [arXiv](https://arxiv.org/abs/2408.05829)，作者补充 [Zenodo](https://zenodo.org/records/11403244)。本地保存 PDF；补充下载若失败见 retrieval-manifest，不虚报运行完整系统。
- 选择优化 [Lin & Bilmes ACL 2011](https://aclanthology.org/P11-1052/)，可核对的官方库 [submodlib](https://github.com/decile-team/submodlib)。预检为明确写出的简化词覆盖实现，不是完整官方库跑分。
- [ReFEree ACL 2026](https://aclanthology.org/2026.acl-long.653/)，作者仓库 [bsy99615/ReFEree](https://github.com/bsy99615/ReFEree)。前一阶段已核查并归档，不将模型检测分数当真值。
- [TRACE 原文](https://arxiv.org/abs/2604.03447)。它对 Java 工件信任进行扰动评估，与“只加来源标签”的候选接近，需要排除重做已有问题。
- [QAEval TACL 2021](https://aclanthology.org/2021.tacl-1.47/)，作者实现 [danieldeutsch/qaeval](https://github.com/danieldeutsch/qaeval)。其原模型依赖另行下载；本原型是有限 API 身份题，不宣称原样复现 QAEval。
- [名称消失研究](https://openreview.net/pdf?id=8t5TlFzUAU) 已研究代码理解中的名称遮蔽。因此遮蔽本身不满足论文新颖性门槛。
- [重要性保留的 conformal 摘要](https://arxiv.org/abs/2509.20461)，[作者实现](https://github.com/layer6ai-labs/conformal-importance-summarization)。已有重要性/覆盖校准；本轮不转为旧压缩主线，也不在没有独立样本时宣称覆盖保证。

生产工程单独保留：宏未展开的部分语法树把 if 误当函数，控制关键字过滤回归通过。该确定性修复不作为研究方法效果。
