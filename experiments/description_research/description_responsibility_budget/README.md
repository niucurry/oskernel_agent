# 职责预算候选：停止

协议先冻结、实际运行，无模型请求。ThreadX 版本与每文件 Git blob/SHA256 已核对；ChibiOS 和 NuttX 只准备了可能的确认输入，**没有用它们确认效果，也没有称为新盲测**。

复现无 API：`python3 preflight.py`。预检独立维护者服务名称参考为 81 个源码实现；功能族是冻结的粗粒度前缀分组，不是标准功能本体，也不是完整运行能力。全部选择器见同一原源码且有相同 UTF-8 上限。

- 12 KB：对象平衡 4 个族/4 个完整服务；简单名称轮询 2 个族/3 个服务。
- 24 KB：对象平衡 4 个族/4 个服务；名称轮询 4 个族/5 个服务。

事前要求两个预算都多至少 10 个百分点且不损失服务数，未通过。不能仅摘 12 KB 的正差异立论文，不继续修改对象组、预算或参考分母。

invalid-v1 保留语法树受宏破坏而产生 if/while 伪函数的无效运行、原因和原冻结。修正为共享 Ctags 定义窗口后重冻、重跑；判为实现错误而不是最初的机制负结果。

production_observation.py 实际执行现有文件抽样与默认阅读。机械按候选顺序装入有限预算不是 LLM 的适应性阅读，也不是生产报告效果；只验证片段暴露情况。它保留了原 reader 文本和生产文件 SHA。

阶段 2 总预算 60 请求/200,000 实际 token/2 小时实验子进程 CPU，独立于上一阶段 35 请求、136,170 已报告 token +1 次未知用量。API 预检余额 1.27 CNY；上一阶段后余额 1.55 不等于免费，后来已有可见扣减。该候选没有模型支出。磁盘约 823 MB 可用，没有内核大构建或大型模型下载。精确全阶段 CPU 累计没有仪表化，脚本墙时及重跑计时另记，不虚报测量值。

下一步并不延长该候选：描述评测的身份线索污染实验见 ../description_anchor_answerability/；本轮仍未建立适合主张的新论文方法。
