实现：本模块以纯宏（macro）形式提供内存对齐（memory alignment）原语，全部集中在 os/rt/include/chalign.h。核心是掩码常量 MEM_ALIGN_MASK(a)（os/rt/include/chalign.h:60），它把对齐值 a 转换为低位置 1 的掩码 (size_t)(a) - 1U，并要求 a 为 2 的幂。向上对齐 MEM_ALIGN_NEXT(p, a)（os/rt/include/chalign.h:79）先加上掩码再复用向下对齐；向下对齐 MEM_ALIGN_PREV(p, a)（os/rt/include/chalign.h:68）用按位与取反掩码实现；对齐判定 MEM_IS_ALIGNED(p, a)（os/rt/include/chalign.h:90）检查掩码位是否全零；合法性校验 MEM_IS_VALID_ALIGNMENT(a)（os/rt/include/chalign.h:98）用 a != 0 && (a & (a-1)) == 0 判定 2 的幂。
主要限制：所有宏均把入参强制转换为 size_t，在 64 位平台上对超过 SIZE_MAX 的指针或长度会截断；MEM_ALIGN_NEXT 在 p 接近 SIZE_MAX 时相加会回绕（os/rt/include/chalign.h:81），源码未做溢出保护。此外该头文件在本仓库快照内无任何调用点，无法从源码证明其被实际使用。
