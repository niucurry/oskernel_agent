【技能：虚拟化（virt）子系统创新性分析】

**触发条件：** 仅当本子系统是「虚拟化 / hypervisor」时加载。用本卡梯度在**子系统总览**写
「创新性分析」。判定**只能引用本卡内容**；无对应机制或与基线一致 → 1–2 分写「存疑」，**禁止
编造**。带 file:line。

━ CPU 虚拟化 ━
- 基线(1分)：无虚拟化。
- 工程(2–3分)：trap-and-emulate 敏感指令、vCPU 上下文保存/恢复、VM 退出处理循环。
- 前沿(4–5分)：硬件辅助虚拟化(RISC-V H 扩展 / x86 VT-x)、嵌套虚拟化。

━ 内存虚拟化 ━
- 基线(1分)：无。
- 工程(2–3分)：影子页表(shadow page table)、GPA→HPA 翻译。
- 前沿(4–5分)：两级页表硬件翻译(EPT/NPT/RISC-V G-stage)、大页客户机映射。

━ 设备虚拟化 ━
- 基线(1分)：无。
- 工程(2–3分)：virtio 设备模拟、MMIO 陷入模拟。
- 前沿(4–5分)：设备直通(passthrough)、IOMMU 隔离、vhost 卸载。

【创新度判定提示】整段取最高对位项。看信号：VM exit 循环、影子/两级页表、H 扩展、virtio 模拟、
直通/IOMMU。无任何虚拟化逻辑则本节不适用。
