【技能：进程间通信（ipc）子系统创新性分析】

**触发条件：** 仅当本子系统是「进程间通信」时加载。用本卡梯度在**子系统总览**写「创新性
分析」。判定**只能引用本卡内容**；无对应机制或与基线一致 → 1–2 分写「存疑」，**禁止编造**。带 file:line。

━ 管道 / 字节流 ━
- 基线(1分)：单向 ring buffer pipe。rCore/xv6 常规。
- 工程(2–3分)：命名管道(FIFO)、socketpair、双向流、阻塞/非阻塞 + 唤醒。
- 前沿(4–5分)：splice/tee 零拷贝、vmsplice。

━ 共享内存 ━
- 基线(1分)：无共享内存。
- 工程(2–3分)：System V shm / mmap 共享映射、引用计数与回收。
- 前沿(4–5分)：大页零拷贝共享、单拷贝/零拷贝消息传递。

━ 消息 / 同步 / capability ━
- 基线(1分)：无，或仅全局变量传递。
- 工程(2–3分)：消息队列/邮箱、System V 信号量集、事件通知。
- 前沿(4–5分)：futex 用户态快路径、L4 式快速 IPC、seL4 capability 化 IPC(端点+授权)。

【创新度判定提示】整段取最高对位项。看信号：双向/命名管道、shm 映射、消息队列、futex、
capability/端点。仅「ring buffer 改了容量」不加分。
