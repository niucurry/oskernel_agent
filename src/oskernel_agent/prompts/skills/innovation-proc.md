【技能：进程 / 线程管理（proc）子系统创新性分析】

**触发条件：** 仅当本子系统是「进程/线程管理」且关注生命周期与模型时加载；**调度算法/上下文
切换/同步原语走 `innovation-sched`**，二者可同时用于「进程管理」子系统。用本卡梯度在**子系统
总览**写「创新性分析」。判定**只能引用本卡内容**；无对应机制或与基线一致 → 1–2 分写「存疑」，
**禁止编造**。带 file:line。

━ 创建 / 销毁 ━
- 基线(1分)：fork 整段拷贝地址空间 + exec 重载；exit 直接回收。rCore/xv6 常规。
- 工程(2–3分)：Copy-on-Write fork(与 mm 协作)、clone 标志位选择共享、vfork、僵尸回收 + wait/waitpid。
- 前沿(4–5分)：posix_spawn、进程快照/恢复(CRIU 思路)、fork 免拷贝优化。

━ PCB / 线程模型 ━
- 基线(1分)：单线程进程，一个 TCB/PCB。
- 工程(2–3分)：多线程(线程组共享地址空间)、用户态线程(M:N)、TLS 线程局部存储、内核/用户线程。
- 前沿(4–5分)：async 任务模型、有栈/无栈协程与线程混合调度。

━ 资源 / 隔离 ━
- 基线(1分)：无资源限制与隔离。
- 工程(2–3分)：fd 表管理、rlimit、进程组/会话、信号定向。
- 前沿(4–5分)：namespace/cgroup 容器化隔离、资源配额与计量。

【创新度判定提示】整段取最高对位项。看信号：CoW fork、clone 标志、线程组/TLS、wait 回收、
namespace/cgroup。仅「改了 PCB 字段」不加分。
