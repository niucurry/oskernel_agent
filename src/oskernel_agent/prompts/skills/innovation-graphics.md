【技能：图形 / 显示（graphics）子系统创新性分析】

**触发条件：** 仅当本子系统是「图形 / 显示 / 终端 / GUI」时加载。用本卡梯度在**子系统总览**写
「创新性分析」。判定**只能引用本卡内容**；无对应机制或与基线一致 → 1–2 分写「存疑」，**禁止
编造**。带 file:line。

━ 显示输出 ━
- 基线(1分)：串口/UART 文本输出。常规。
- 工程(2–3分)：framebuffer 直写像素、virtio-gpu 设备、分辨率/像素格式管理。
- 前沿(4–5分)：双缓冲/垂直同步、2D 硬件加速、DMA 刷屏。

━ 终端 / 控制台 ━
- 基线(1分)：直接打印，无控制序列。
- 工程(2–3分)：ANSI 转义解析、字体渲染、滚动/光标、tty 行规程。
- 前沿(4–5分)：多终端复用、合成控制台。

━ 窗口 / GUI ━
- 基线(1分)：无。
- 工程(2–3分)：基础窗口/控件、事件分发(鼠标/键盘)。
- 前沿(4–5分)：窗口合成器、GUI 框架、多窗口 Z-order 与裁剪。

【创新度判定提示】整段取最高对位项。看信号：framebuffer/virtio-gpu、ANSI/字体渲染、双缓冲、
窗口合成/事件分发。仅「换了打印宏」不加分。
