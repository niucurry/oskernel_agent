【技能：trap / 中断（trap）子系统创新性分析】

**触发条件：** 仅当本子系统是「trap / 异常 / 中断 / 系统调用入口」时加载。用本卡梯度在
**子系统总览**里写一节「创新性分析」（不写进模块详细）。判定**只能引用本卡内容**；无对应机制
或与教学基线一致 → 定 1–2 分并写「与标准做法一致 / 无法对标前沿，存疑」，**禁止编造**。带 file:line。

━ 异常 / 中断分发 ━
- 基线(1分)：单一 `trap_handler` 按 scause 大 match 分发，stvec 直接模式。rCore/xv6 常规。
- 工程(2–3分)：向量化中断(stvec vectored)、中断号表驱动分发、外部中断经 PLIC 路由、嵌套中断管理。
- 前沿(4–5分)：中断线程化(threaded IRQ)、软中断/tasklet/下半部、用户态中断(N 扩展 user-level interrupt)。

━ 上下文保存 / 特权级切换 ━
- 基线(1分)：`TrapContext` 全量保存 32 通用寄存器，跳板页 `__alltraps/__restore`。
- 工程(2–3分)：惰性/精简寄存器保存、FPU 状态按需保存、内核态 trap 与用户态 trap 分离处理。
- 前沿(4–5分)：快速系统调用路径(类 syscall/sysret 优化)、vDSO 式免陷入调用。

━ 信号 ━
- 基线(1分)：无信号机制，或仅占位。
- 工程(3分)：POSIX 信号（注册/递送/默认动作/信号掩码/用户态 handler + sigreturn 栈帧）。
  有完整递送+返回路径才给 3。
- 前沿(4–5分)：实时信号排队、signalfd、per-thread 信号定向。

━ 定时器 / 抢占 ━
- 基线(1分)：固定时间片 timer 中断触发调度。
- 工程(2–3分)：分层时间轮 / 红黑树定时器、内核抢占点、tickless(动态 tick)。
- 前沿(4–5分)：高精度定时器(hrtimer)、全抢占(PREEMPT_RT) 式低延迟。

【创新度判定提示】整段取最高对位项。看信号：向量化/表驱动分发、PLIC 路由、下半部机制、
信号的 sigreturn 路径、定时器数据结构、抢占/tickless。仅「match 多加几个 case」不加分。
