【技能：设备驱动（driver）子系统创新性分析】

**触发条件：** 仅当本子系统是「设备驱动」时加载。用本卡梯度在**子系统总览**里写一节
「创新性分析」（不写进模块详细）。判定**只能引用本卡内容**；无对应机制或与教学基线一致 →
定 1–2 分并写「与标准做法一致 / 无法对标前沿，存疑」，**禁止编造**。带 file:line。

━ 驱动框架 / 设备模型 ━
- 基线(1分)：每个设备写死的 MMIO 读写函数，无统一抽象。rCore/xv6 常规。
- 工程(2–3分)：统一 Device trait / 驱动注册表、设备树(FDT)解析探测、设备生命周期与电源管理。
- 前沿(4–5分)：用户态驱动(类 microkernel/IDL)、Rust 类型状态保证寄存器访问安全、热插拔。

━ 总线 / virtio ━
- 基线(1分)：直接按 virtio-mmio 寄存器手工初始化单设备。
- 工程(2–3分)：virtio 通用层(virtqueue 抽象)复用于 blk/net/gpu、PCI 枚举、特性协商。
- 前沿(4–5分)：virtio-pci 现代设备、indirect/packed virtqueue、vhost/用户态后端。

━ 块设备 / 中断驱动 IO ━
- 基线(1分)：轮询式同步读写一个扇区。
- 工程(3分)：中断驱动异步 IO + 请求队列、块缓存对接、批量/合并请求。有中断完成路径才给 3。
- 前沿(4–5分)：多队列(blk-mq)、io_uring 风格提交/完成队列、NVMe 式深队列。

━ 网络 / DMA ━
- 基线(1分)：无网络，或纯拷贝 PIO。
- 工程(2–3分)：DMA 环形缓冲(rx/tx ring)、网卡中断 + 协议栈对接、零拷贝收发。
- 前沿(4–5分)：NAPI 式中断缓和、XDP/用户态网络(DPDK 思路)、RSS 多队列。

【创新度判定提示】整段取最高对位项。看信号：Device trait/注册表、FDT 探测、virtqueue 复用、
中断驱动 + 请求队列、DMA ring、多队列。仅「换个设备基址常量」不加分。
